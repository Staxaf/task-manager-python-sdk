Task Management API

Task Management API

REST API for managing users, projects, tasks, and comments. A Project owns many Tasks; a Task owns many Comments. Users optionally own projects, are assigned tasks, and author comments. Deletes cascade Project → Task → Comment; user FKs are set null.

Error responses

StatusMeaning
404User, project, task, comment, or related FK target not found
409Conflict (duplicate user email)
422Request validation failed (body / path / query)
